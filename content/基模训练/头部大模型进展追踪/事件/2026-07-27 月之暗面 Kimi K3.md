# 月之暗面 Kimi K3

> [!summary] 当前判断
> K3 是首批把**序列、深度、MoE 宽度、长程 Agent 训练和推理系统**一起公开解释的 3T 级开放权重模型。它的架构增量比多数点版本更实质，但 2.8T 总参数、104B 激活参数、定制注意力与许可证条件让“开放”不等于“容易部署”。

## 发生了什么

月之暗面先在产品中引入 Kimi K3，并承诺在 2026-07-27 前发布完整权重；随后公开 2.8T 权重、技术报告和架构材料。模型使用 69 层 KDA + 24 层 Gated MLA、Attention Residuals、Stable LatentMoE，支持 1M context 与原生视觉输入。

详细技术拆解见 [[Kimi K3 核心技术解析：三维信息流、百万上下文与长程 Agent 训练]]。

## 相对 K2 系列的真实增量

- **序列轴：** KDA 用固定状态承担大部分长序列记忆，MLA 周期性恢复精确全局交互。
- **深度轴：** Attention Residuals 让后层主动检索早期 block 表征，而不是只沿均匀残差流累积。
- **宽度轴：** Stable LatentMoE 在较窄潜空间激活 16/896 专家，并配套负载平衡与专家并行。
- **训练—服务协同：** 长程 Agent RL、可暂停环境、QAT、MXFP4/MXFP8、推测解码和 KDA/MLA 联合前缀缓存共同进入方案。
- **开放范围扩大：** 发布权重、配置、推理建模代码和多个组件；但数据、奖励资产和端到端训练流水线未完整公开。

## 外部反馈

### 独立评测

[Artificial Analysis](https://artificialanalysis.ai/models/kimi-k3) 当前最大努力档给出 Intelligence Index 57，在其大体量开放权重模型组中处于最前；同时记录约 34.9 output tok/s，每百万 token 输入价格为 3 美元、输出为 15 美元，评测总输出约 130M token。它的结论是能力强，但明显慢、贵且冗长。

### 开放生态与开发者讨论

开源社区的第一反应大量集中在 llama.cpp/MLX/推理引擎适配与显存门槛，而不是“能否在单机运行”。官方也建议 64 个以上加速器的 supernode 部署，这说明 K3 的开放价值更偏研究、云部署和架构透明度，而不是消费级本地推理。

官方完整表格对多种模型使用了 Kimi Code、Claude Code 或 Codex 等不同 harness，部分硬件和 fallback 也不同。它能展示系统级竞争力，不能直接当纯模型排行榜。

## 代价与边界

- 2.8T total / 104B active，权重约 1.56 TB；部署和通信复杂度极高。
- Kimi K3 License 对大规模 MaaS 和超大产品有额外条件，不是 MIT/Apache-2.0。
- 官方“2.5× scaling efficiency”是内部组合配方的 loss/compute 位移，不等于推理成本降低 2.5 倍。
- 官方限制说明提到 thinking history 敏感与过度主动；harness 不兼容或中途换模型可能导致质量不稳定。

## 下一步验证

一组测试固定 Kimi Code / Claude Code harness、工具、effort 和预算，比较 K3、GLM-5.2、DeepSeek V4 Flash 与闭源模型的长程成功率。另一组收集 vLLM/SGLang 实际部署的吞吐、显存、并行配置和缓存命中，判断架构效率是否变成任务成本优势。
