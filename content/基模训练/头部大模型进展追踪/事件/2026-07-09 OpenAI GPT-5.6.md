# OpenAI GPT-5.6

> [!summary] 当前判断
> GPT-5.6 的真实增量不是再提高一个综合分，而是把**前沿上限、日常成本档、长程 Agent、程序化工具编排和成品级视觉判断**合并成一个可按任务调度的家族。外部证据支持“能力强”，但尚不支持“所有任务都更便宜”：最大努力档的等待、单价和 token 仍可能主导总成本。

## 发生了什么

OpenAI 于 2026-07-09 将 GPT-5.6 推向 GA，分为旗舰 **Sol**、平衡档 **Terra** 和低成本档 **Luna**。Responses API 同时加入 Programmatic Tool Calling 与 beta multi-agent；官方还给出显式 cache breakpoint 和至少 30 分钟的缓存存活契约。

## 相对 GPT-5.5 的真实增量

- **能力分层变成稳定产品接口：** 不是只给一个“大/小”模型，而是让 Sol、Terra、Luna 各自占据能力—成本工作点。
- **Agent 编排进入模型 API：** 程序化工具调用允许模型在内存中写程序协调工具，多 Agent 允许并发子任务后统一综合。
- **成品质量成为目标：** 官方重点展示电脑操作、前端视觉检查、演示文稿、文档和电子表格，而不仅是代码补全。
- **效率主张从单 token 价格转向每项成功工作：** 官方多次用更少步骤、工具调用和 token 解释改进，但这些数字大多来自内部或合作伙伴评测。

## 外部反馈

### 独立评测

[Artificial Analysis](https://artificialanalysis.ai/models/gpt-5-6-sol) 在 2026-08-03 抓取的最大努力档结果中给出 Intelligence Index 59、约 67.7 output tok/s、1M context；每百万 token 输入价格为 5 美元、输出为 30 美元。它的总结是能力位于前沿，但同价位下偏贵、偏慢且略冗长。最大努力档约 123 秒的 time-to-first-token 是特定服务与推理设置下的测量，不能外推到 Terra、Luna 或较低 effort。

### 市场与开发者信号

官方发布页收录了多家早期伙伴对长程编码、金融研究、文档与设计产物的正面评价；这些材料能说明采用方向，却带有 early-access 与合作选择偏差，不能替代独立复现。

## 代价与边界

- 闭源，参数、训练数据和完整训练配方未公开。
- Sol 的单 token 价格高；若任务不需要最高能力，模型路由比“默认用 Sol”更重要。
- 跨模型 Agent 分数混入 Codex harness、effort、工具、并行策略和安全 guard，不能当作纯 base model 排名。
- `ultra` 会协调多个 Agent，质量、耗时和成本都不应与单 Agent 的 `max` 直接横比。

## 下一步验证

固定 20 个本地任务，分别用 GPT-5.5、GPT-5.6 Sol/Terra/Luna 运行，记录成功率、总输入/输出 token、缓存命中、重试、工具调用、人工返工和端到端成本。只有任务级经济性改善，才能确认“more intelligence per token”转化为生产价值。
